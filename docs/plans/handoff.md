## Подготовка машины

```bash
scripts/install-hooks.sh                      # pre-commit / pre-push (fmt, check, check-data; clippy и тесты в release)
cd client && npm install && npm run wasm      # клиентский WASM в git не хранится
npm run dev                                   # клиент: http://localhost:5173/  (?scenario=sinai67 или выбор в меню)
```

- **WASM пересобирать после любой правки ядра, `crates/wasm` или `data/*.json`** (`cd client && npm run wasm`): иначе клиент падает на загрузке данных («unknown field …», «missing field …»).
- `sim ai-vs-ai` по умолчанию сажает «жадину» за обе стороны — для ИИ v1 нужен `--players v1,v1`; `--set` меняет только `rules.json` (для `ai.json` — копия папки данных и `--data`).
- Правила процесса — в `CLAUDE.md` (раздел «Решения дизайнера о работе агента», туда перенесена память Claude) и AGENTS.md; кратко: коммиты без строк соавторства (никаких `Co-Authored-By`); пушить после каждого закрытого пункта; `--no-verify` нельзя; проверка и коммит — через `&&`; PDF руководства SC в `docs/` — в `.gitignore`, из истории не удалять; правки GDD — только через живой документ и экспорт снимка.
