# Клиент Ceasefire Line

TypeScript + PixiJS + Vite; правила — ядро на Rust, собранное в WASM (`crates/wasm`).

Установка, сборка, запуск игры и редактора — в [README.md](../README.md) в корне репозитория. Коротко:

```bash
npm install && npm run wasm && npm run dev   # игра: http://localhost:5173/, редактор: http://localhost:5173/?mode=edit
```
