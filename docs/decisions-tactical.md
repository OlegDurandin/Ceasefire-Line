| 2026-11-27 | R-TAC-03, T-SUP-01/02 | Данные поддержки — в снимке ядра | Решение дизайнера, сделано добавочно: `TacticalSide.support` (`TacticalSupport`, `serde(default)` — старые снимки читаются) заполняет `GameState::snapshot` через новый только читающий `tactical_support`: снабжение лучшей своей артиллерии, достающей до гекса боя; ударная авиация, способная долететь сейчас (не летала, не перебазировалась) — число вылетов, снабжение базы лучшей из них и её готовность; зонтик ЗРК противника над гексом; рейтинг штаба бригады; классы своих боевых бригад в соседних гексах (резерв); свои инженеры в 2 гексах. Тактика читает поддержку из снимка (`BattleInput` = только снимок), авиаудары ограничены числом вылетов; `sim --dump-battles` больше ничего не собирает. Стратегия не меняется: снимок строится только при объявлении тактического боя. Тест ядра `snapshot_carries_the_support_of_both_sides`. Повтор приёмки T-RES-05 на перевыгруженных 926 снимках: те же цифры (среднее 50,1, «Голаны» 49,5, «Синай» 50,3, децили 8,8–12,2%). |
| 2026-11-27 | T-RES-05 (новое, вместо T-RES-02 для кампании) | Перцентиль итога (открытый вопрос 4) | Решение дизайнера. В начале боя кампании — 40 прогонов снимка ИИ против ИИ (`data/tactical.json` → `result.t_res_05.runs`), сиды выводятся из сида боя (SplitMix64, `battle::reference_seeds`). Перцентиль = (прогонов с M < M игрока + ½ × с M =) / 40 × 100 в пределах [2,5; 97,5]; название итога: ≥ 90 разгромная победа, 65–90 победа, 35–65 ничья, 10–35 поражение, < 10 разгром. Потери — по R-TAC-02 (защитник на перцентиле, атакующий на зеркальном). Реализация: `Battle.reference` (если задан — итог по T-RES-05, иначе пороги T-RES-02 для отдельных боёв), прогоны — `ceasefire_ai::tactical::{reference_margins, campaign_battle}`, WASM — `tacticalReferenceMargins`. Найдено при приёмке: малые сиды (1, 2, …) давали скоррелированные первые выборки PCG и смещали карту — сид боя теперь перемешивается SplitMix64 перед генератором. Приёмка (`sim tactical --res05 true`, 200 снимков × 10 сидов, у каждого снимка свои сиды боя): средний перцентиль 50,1 («Голаны» 49,5, «Синай» 50,3 — цель 50 ± 2); децили 8,8–10,7%, верхний 12,2% — на сетке шага 1,25 верхний дециль [90; 100] содержит 9 значений из 81 против 8 у остальных, ожидание 11,1%, отклонение в пределах шума; время 40 прогонов — native 133 мс (под нагрузкой 18 потоков), WASM в node 82 мс (медиана 79, максимум 146). Вопрос закрыт. |

| 2026-11-27 | T-TECH-01, T-TECH-02 | Тактический ИИ и пороги T-RES-02 | ИИ (`ceasefire_ai::tactical`): один приказ за вызов; вызов поддержки — авиация, затем артиллерия, затем миномёт по самой ценной видимой цели, без видимых целей наступающий ставит дым перед передовым юнитом; затем лучшее из: огонь (ожидаемый урон × ценность цели, ×1,5 на ключевой точке), штурм при положительном размене, ход к ключевым точкам (наступающий — к не своим, защитник — ко всем) по укрытиям и с меньшим числом видящих противников, наблюдение, окапывание защитника; веса × (1 ± 0,25) по сиду.
